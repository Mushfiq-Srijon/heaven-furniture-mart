# Heaven Furniture Mart

A conversion-focused luxury landing page for **Heaven Furniture Mart**, a bespoke furniture studio based in Agrabad, Chattogram, Bangladesh.

The website is designed to feel like a **luxury furniture and interior studio rather than an online furniture marketplace**, with an editorial visual style, real furniture imagery, subtle animations, and a clear focus on generating customer inquiries through WhatsApp.

## ✨ Features

* Luxury, editorial-inspired responsive design
* Animated splash screen with logo transition
* Full-screen hero section
* Brand introduction and founder statement
* "Why Heaven" trust section
* Interactive furniture collection carousels

  * Living Room
  * Bedroom
  * Dining
  * Office & Study
* Dedicated bespoke/custom furniture section
* Step-by-step custom order process
* Company milestones timeline
* Founder social proof and business statistics
* Showroom information with embedded Google Maps
* WhatsApp conversion-focused CTAs
* Floating WhatsApp contact button
* Responsive mobile navigation
* Scroll-based section reveal animations
* Active navigation section highlighting
* Touch and mouse drag support for collection carousels
* Reduced-motion support for accessibility
* SEO and social sharing metadata
* Responsive layout optimized for mobile and desktop

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Mushfiq-Srijon/heaven-furniture-mart.git
cd heaven-furniture-mart
npm install
```

### Development

Start the Vite development server:

```bash
npm run dev
```

The application will be available at the local URL shown by Vite.

### Production Build

Create an optimized production build:

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Lint

Run ESLint:

```bash
npm run lint
```

## 🎨 Design Direction

The visual identity follows the brand's requested luxury aesthetic:

* **Deep Charcoal-Teal** — primary dark background
* **Warm Ivory** — light sections and backgrounds
* **Muted Gold / Brass** — restrained accent color
* **Deep Brown** — typography and grounding tones
* **Natural Wood Tones** — material-inspired visual language

Typography combines **Cormorant Garamond** for elegant editorial headlines with **DM Sans** for clean supporting text and UI elements.

The design intentionally avoids the crowded appearance of a traditional furniture e-commerce website.
